# distritoEscolarABC
Base de datos de Un sistema de registro.

Propuesta a la siguiente problemática. 

"
El distrito escolar ABC desea crear un sistema de registro e información del alumno en línea para recopilar información 
relacionada con los alumnos. El sistema se debe diseñar como un proceso en línea para permitir que los nuevos alumnos se 
registren en línea. También debe permitir que los alumnos existentes actualicen y revisen toda la información. Cree una lista de 
los datos importantes que se deben recopilar y almacenar en la base de datos de registro de alumnos.
"

Dada la poca información se hace una pequeña delimitación teniendo en cuenta que el ejercicio plantea solo un registro de usuarios y puesto es información del estudiante se pone a la par si se desea saber el semestre. 
Este ultimo no es necesario, pero es parte de información clave si se necesitara. Se agrega contacto del mismo estudiante y contacto de emergencia ( Tomando en cuenta no centrarse en que puede ser papá o mamá). 
Se puede optar por crear un apartado de Madre o Padre si asi se desea. Se puede incluir NSS, CURP si asi lo desea puesto que solo pide un registro. 
Si se ve el alcance de la problemática más alla de un simple registro, se toman como datos importantes tanto de el alumno como el tutor responsable.
